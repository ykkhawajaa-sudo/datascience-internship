# Customer360

Customer Lifetime Value & Churn Intelligence System — DS-01 portfolio project.

This folder contains the project source, documentation, tests, and dashboard. The initial scaffold is being published in stages; model metrics are not claimed until the training pipeline has been run and validated.

## Planned capabilities
- LightGBM churn prediction
- Kaplan–Meier and Cox survival analysis
- Transparent CLV estimation
- K-Means customer segmentation
- Clearly labelled simulated retention-offer uplift demo
- Streamlit dashboard and optional PostgreSQL persistence

## Methodology limitation
IBM Telco Customer Churn does not include randomized retention-offer assignment and outcomes. Any synthetic treatment/uplift output is a demonstration only, not causal evidence.
